# CanSat 2輪誘導 EKF + 方位PID MATLABシミュレーション

リポジトリ直下の要件書 `EKF設計及びシミュレーション方法.md` に基づく実装。
`run_simulation.m` を実行すると次の順に閉ループで走る。

| フェーズ | 内容 | EKF |
|---|---|---|
| Phase 0 | 静止して GNSS を `N_avg` 回測位 → 出発地点 `P_start` | 未起動（IMU 蓄積） |
| Phase 1 | `v_cal` で `t_cal` 秒直進 | 未起動 |
| Phase 2 | 静止して再測位 → 初期地点 `P_init`、バイアス推定、x0・P0 算出 | 未起動（IMU 蓄積） |
| Phase 3 | EKF 推定値にもとづく方位 PID 誘導。`d̂ ≤ d_stop` が連続 `N_stop` 回で急停止 | 稼働 |
| Phase 4 | 停止後 `t_post` 秒記録して終了 | 稼働 |

真値との比較による精度評価は行わない。内部の運動モデルはセンサ疑似観測を作るためだけに使い、
推定値・共分散・イノベーション・誘導挙動を観察する（要件書5章）。追加 Toolbox 不使用。

## 要件書に書かれていない部分の判断

- **時刻の対応**：ステップ k の運動モデル更新で実現した速度 v・角速度 ω を「k→k+1 区間の値」とし、
  `a_meas(k)`, `ω_meas(k)` もその区間の値とした。エンコーダ更新の `h_enc` もこの `ω_meas(k)` を使う。
- **PID の D 項に使うジャイロ**：制御則は運動モデル更新より前に実行されるため、
  その時点で手に入る最新のジャイロ値（直前ステップのもの）を使う。
- **停止判定のタイミング**：ステップ末の EKF 更新後の推定値で判定し、成立したら次のループから指令 0。
- **バイアス推定**：Phase 0 全体と、Phase 2 の冒頭 `t_settle`（0.5 s）を除いた区間の IMU 平均。
  Phase 2 の最初のステップには停止時の加速度スパイクが乗るため除外している。
  `sigma_ba0`, `sigma_bg0` は `[]` のとき「標準誤差 × `bias_se_margin`(=3)」で自動算出（数値を入れれば固定値）。
- **P0(θ) の上限**：`D` が極端に小さいと式が発散するので `P0_theta_max = π²` でクリップする。
- **疑似 COG**：NMEA と同様に [0, 2π) で出力。EKF 側の θ は折り返さない（連続値）。

## 実行結果（既定パラメータ、seed 43）で分かったこと

- 誘導は収束し、t ≈ 268 s（誘導開始から約 238 s）で推定ゴール距離 2.95 m で急停止。
- エンコーダ・GNSS 位置のイノベーションは約 99 % が ±3√S に収まり、整合している。
- **COG のイノベーションは ±3√S に 3 % しか収まらない**。巡航 0.2 m/s では疑似 COG の実効ノイズが
  `sqrt(0.5² + (σ_sog/v)²) ≈ 29°` なのに対し、EKF の `R_cog` は 0.5° のままなのでフィルタが COG を過信している。
  その結果、COG 更新のたびに θ と、θ と相関する b_g が引っ張られ、b_g 推定値が ±3 °/s 程度跳ねる。
  （比較：COG 無効 → b_g は 0.26〜0.35 °/s で安定。`sigma_cog = 30°` → COG の 97 % が ±3√S 内、b_g も安定）
  要件書どおり `R_cog = σ_cog²`（定数）で実装してあるので、`sigma_cog` を走行試験の実測値で決めるか、
  R_cog を SOG 依存にするかは設計側で判断すること。
- `v_threshold = 0.2 m/s` と `v_cruise = 0.2 m/s` が同じ値なので、走行中でも COG 更新の約半分がゲートされる。
